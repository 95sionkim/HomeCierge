# HomeCierge PRD 결정 기록

2026-11-10의 사용자 답변 36개를 PRD v1.0의 요구와 수락 기준에 반영했다. 2026-11-22에 같은 날 입금·납부의 표시 방식을 Q-37로, 2026-11-26에 공급면적 대응 근거·대표 좌표·LLM 연결·면적 범위 변경 상한·출처별 LLM 입력 허용·기준 모델 변경을 Q-38~Q-43으로, 2026-11-27에 카카오 좌표 보관·출퇴근 출발지·운영 DB 분리·대중교통 조회 방식·공고 PDF 출처 허용을 Q-44~Q-48로, 2026-11-28에 공고 PDF 서식 판단(열린 층 구간·계약면적 반올림·미포함 옵션)을 Q-49~Q-51로, 평형 단위 비교를 Q-52로 추가했다. 아래 표는 [현행 PRD v1.3](01-product-prd.md)의 해당 절로 연결한다. 이 기록의 ‘확정’은 해당 제품 선택에 대한 것이며, 미정 설계의 채택·제품 구현·출시 검증 완료를 뜻하지 않는다. 리뷰 처리와 남은 검증은 [보완 추적표](03-review-resolution.md)를 따른다.

## 3. 사용자 결정과 기술 확인을 구분한다

- 공급면적의 실제 대응 가능률, 권리 거래의 식별 필드, PDF 서식·정정 관행, 외부 자료 이용 조건은 자료 확인이 필요한 사항이다. 사용자의 선택만으로 확인 완료로 바꾸지 않는다.
- 리뷰에서 재현한 인증값 정제 문제와 역사적 연결기의 식별자 정렬 오류는 구현 작업으로 추적한다. PRD 문구 변경으로 수정 완료가 되지 않는다.
- 사용자 답변이 필요한 항목은 한 번에 두세 가지씩 묻는다. 이미 확정된 요구를 다시 선택하게 하기보다 미정 세부 동작을 구체화한다.
- 답변을 받으면 관련 R/P/D/A를 함께 갱신한다. 최종 문서에는 초기 범위의 결정, 후속 범위, 데이터·운영 검증 조건, 검수 시나리오가 서로 일치해야 한다.
