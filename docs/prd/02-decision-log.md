## 3. 사용자 결정과 기술 확인을 구분한다

- 공급면적의 실제 대응 가능률, 권리 거래의 식별 필드, PDF 서식·정정 관행, 외부 자료 이용 조건은 자료 확인이 필요한 사항이다. 사용자의 선택만으로 확인 완료로 바꾸지 않는다.
- 리뷰에서 재현한 인증값 정제 문제와 역사적 연결기의 식별자 정렬 오류는 구현 작업으로 추적한다. PRD 문구 변경으로 수정 완료가 되지 않는다.
- 사용자 답변이 필요한 항목은 한 번에 두세 가지씩 묻는다. 이미 확정된 요구를 다시 선택하게 하기보다 미정 세부 동작을 구체화한다.
- 답변을 받으면 관련 R/P/D/A를 함께 갱신한다. 최종 문서에는 초기 범위의 결정, 후속 범위, 데이터·운영 검증 조건, 검수 시나리오가 서로 일치해야 한다.
