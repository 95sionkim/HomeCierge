# 필요 데이터와 실제 확보 대응표

**최신 범위: 호가를 제외하고 최근 실거래가만 가격 비교에 사용한다.** 공공 API 6종·카카오·법령·ODsay·뉴스를 포함한 10서비스·14조회 모두 실제 응답을 확보했다. [prd-readiness](prd-readiness.md) 참조.

2026-11-06의 실제 API 응답 19개와 공식 공고 PDF 검수에 2026-11-09의 3종 API·12개월 거래·단지 연결 검증을 합친 상태다. 최신 증거는 [validation-20261109](validation-20261109.md)에 있다. 같은 단지의 다른 회차 PDF1건은 병합 거부 검증에만 사용했다. **확보는 샘플에서 확인했다는 뜻이며, 모든 공고·단지에서 항상 제공된다는 의미는 아니다.** 원문은 저장소에 포함하지 않는다. 아래 경로는 원 프로젝트의 비공개 로컬 위치다. 기존 원문은 `api-evidence/20261106_live/`, 해당 필드별 존재/값 보유 수는 그 폴더의 `field-coverage.csv`에서 확인한다. 신규 원문 경로는 `docs/api/live-manifest-20261109.json`과 최신 보고서에 기록했다. PDF 보충값과 페이지 근거는 `pdf-evidence/2026930040/combined.json`, 설명은 [pdf-supplement-validation](pdf-supplement-validation.md)에서 확인한다.

## 판정 용어

- **확보**: 샘플의 실제 값과 필드 의미를 확인했다.
- **일부 확보**: 필요한 정보 중 일부만 제공되거나, 필드는 있지만 값이 비어 있다.
- **원문 필요/미확보**: 공고 PDF 또는 다른 자료가 필요하다. 현재 분석 가능하다고 표시하지 않는다.
- **입력·계산 필요**: 사용자 확인이나 계산을 거쳐 만들어야 한다.
