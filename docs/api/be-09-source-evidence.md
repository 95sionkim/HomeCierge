## 구현의 동작을 검수한다

- **법령 수집기.** 2026-11-09 보관본을 `collect_law_reference`에 메모리에서 재생했다. `286965`·`008243`·공포일·시행일을 다시 얻었고, 고정 키워드로 고른 11건의 조문 번호·가지번호·제목만 남겼다. `2026-06-14`의 목록 재생은 `279483`을 선택했다. 합성 2페이지 중 2페이지 오류, 미래 공포 후보, 같은 시행일의 복수 MST도 각각 보류·제외·보류로 재현했다. [수집기](../../scripts/collect_law_evidence.py)
- **조회와 저장.** 백엔드 모의 요청과 메모리 DB(PGlite)의 합성 Auth 검사에서 타인·다른 분석의 수집본 404, 수집된 공고일 미확인 시 `reference: null`, 공고일이 확인돼도 당일 법령 게시본이 없으면 `version_unverified`를 확인했다. `available`에서도 예외와 경과규정은 `requires_review`, 개인 자격은 `not_assessed`다. 기존 BE-08 검사 3건을 다시 실행해 공식 PDF 저장 권한 미허용 시 새 수집본 저장 차단, 보관 한도 미집행 시 보류, 표시·재사용 철회 뒤 일정 보류와 보유 자금 유지를 확인했다.
