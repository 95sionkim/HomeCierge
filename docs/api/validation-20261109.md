3종 저장 응답 검사 80/80을 통과했다. 뉴스 검색어에 지역명이 포함되어도 관련 기사라는 보장은 없다. 서로 다른 URL 확인도 의미 중복 제거가 아니다.

## 현재 요구와 시험을 구분한다

사용자 결정으로 **5km를 폐기하고 같은 법정동 우선→정상 0개이면 같은 구**로 변경했다. 동에 1~4개이면 구에서 보충하지 않는다. 면적 대응 미확인·연결 보류·부분 수집·오류가 있으면 정상 0개를 확정하지 않는다.

새 동→구 흐름, 공급면적 대응, 후보 선정, 다중 채팅·프로필 기능은 아직 구현·검증하지 않았다. 코드와 문서에 남긴 과거 시험 조건은 재현용이다. 공급면적과 전용면적, 본체·필수 옵션·총취득비용을 구분하는 [PRD](../prd/01-product-prd.md)를 따른다.

## 재현 범위를 확인한다

- 기본 공개 테스트: `python3 -m unittest discover -s scripts -p 'test_*.py' -v`. 합성 자료만 사용한다.
- 과거 실응답 재검증: [기존 manifest](live-manifest.json)·[추가 manifest](live-manifest-20261109.json)와 원 프로젝트의 비공개 증거가 필요하다. 원문 이용·보관·공유 조건도 별도로 확인한다.
- 새로운 API 호출은 새로운 스냅샷이다. 당시 총건수나 날짜와 같은 값을 기대하는 과거 검증기를 그대로 적용하지 않는다.
- 공개 자료를 정리하면서 API를 다시 호출하지 않았다. 과거 보고서 해시는 자료를 나중에 대조하기 위한 값이며 원문 접근이나 독립 검증을 대신하지 않는다.

호출 설정은 [probes.json](probes.json), 필드는 [데이터 대응표](data-requirements.md), 파일별 실행 조건은 [API 안내](README.md)를 참고한다.
