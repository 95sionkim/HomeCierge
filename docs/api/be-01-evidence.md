# BE-01 자료 검증 착수 기록 — V1~V4

2026-11-21. 비교 로직·자료 검증 담당이 [개발 계획 §7](../development-plan.md#7-데이터-성립-검증을-개발과-병행한다)의 V1~V4를 시작하면서 남긴 **조사 착수 기록과 인계 자료**다. 공식 기관의 공개 설명, 데이터 카탈로그, 공식 개발 문서, 법령 원문만 열람했다. 이 문서는 R/P/D/E/A의 상태를 바꾸지 않으며 완성된 검증이나 제품 결정이 아니다. 요구 기준은 [PRD v1.1](../prd/01-product-prd.md)이다.

| 수행 범위를 기록한다 | 이번에 하지 않은 일을 기록한다 |
| --- | --- |
| 공개 문서 26건 열람 시도(아래 표의 행 기준, 성공 22·부분 1·실패 3). 웹 검색 6회(1회 오류)는 공식 주소를 찾는 데만 사용 | 제품 데이터 API 실호출 0회, 원응답 저장 0건, 공고 PDF 다운로드·열람 0건 |
| 카탈로그 페이지에 내장된 공식 명세(OpenAPI)와 법령 조문을 기존 근거와 대조 | 기존 비공개 원응답·PDF, `.secrets/` 열람 없음. 첨부 기술문서(hwp·docx·zip)는 받지 않음 |
| 열람한 페이지는 작업 세션의 임시 폴더에서만 읽음 | 저장소에 원문이나 페이지 사본을 추가하지 않음 |

판정 용어는 다음과 같다. **확인**은 열람한 공식 문서에 해당 문구나 필드가 있다는 뜻이다. **미제공**은 이번에 확인한 공식 명세의 출력 목록에 해당 항목이 없다는 뜻이며, 실제 응답에도 없다고 보증하지 않는다. **추가 조사**는 후보 경로가 있으나 문서만으로 판정하지 못했다는 뜻이다. **미확인**은 공개 문서로 판단하지 못했다는 뜻이고 사유를 함께 적는다. **기술적 가능**은 필드와 호출 경로가 있다는 뜻일 뿐 이용 허락을 뜻하지 않는다.

## 2. V1 — 공급면적·단지·권리 식별

### 2.1 검토 모집단과 집계를 분리한다

**실거래 검토 표본은 0건이며 현행 공급면적 대응 비율은 산출하지 않았다.** 공개 문서만으로는 개별 거래의 공급면적 C를 얻을 수 없다. 이번에 확인한 두 실거래 명세의 출력 목록에는 공급면적이 없고 `excluUseAr`(전용면적)만 있다. 대장·인허가 경로는 실제 응답과 같은 단지 공고의 기준 결과가 있어야 판정할 수 있다. 실응답 조회와 PDF 열람은 이번 작업 범위 밖이다.

과거의 75개 후보·33개 연결·42개 보류는 **전용면적 ±1㎡·5km 주소 연결 시험**이다. 공급면적 대응 결과가 아니므로 아래 명세 집계와 실거래 표본 어디에도 넣지 않았다. [E-04](../prd/01-product-prd.md#122-기존-검증-근거와-적용-한계)의 범위는 그대로 둔다.

실제로 검토한 모집단은 **공급면적 대응 경로 후보가 될 수 있는 공식 명세 7개**다. 질문은 “이 명세가 거래 면적과 공급면적을 연결할 필드를 제공하는가”다.

| 검토한 명세 | 판정 | 근거와 의미 |
| --- | --- | --- |
| 아파트 매매 상세 | 미제공 | 출력 목록의 면적 필드는 `excluUseAr` 하나. 공급면적을 직접 주는 경로가 아님 |
| 분양권전매 | 미제공 | 출력 목록의 면적 필드는 `excluUseAr` 하나 |
| 공동주택 단지 목록 | 미제공 | 출력 목록에 면적 필드 없음 |
| 공동주택 기본 정보 V5 | 미제공 | 전용면적 구간별 세대수(`kaptMparea60`~`136`), 단지 전용면적합, 관리비부과면적만 있음 |
| 청약홈 주택형 조회 | 직접 제공(공고 쪽) | APT·잔여세대 주택형 조회에 `SUPLY_AR`(공급면적)이 있음. 선택 주택형 S의 출처이며 거래 C의 경로는 아님. 임의공급 주택형 조회에는 `SUPLY_AR`이 없음 |
| 건축물대장 전유공용면적 | 추가 조사 | 호 단위 전유·공용 면적은 있으나 주거공용과 그 밖의 공용을 나누는 필드가 없음. 실거래와 공통 키 없음 |
| 주택인허가 전유공용면적 | 추가 조사 | `mgmTypeOulnPk`로 형별 연결 가능성이 있음. 주거공용 구분 필드가 없고, 사업계획승인 자료가 준공 후 변경을 반영하는지 미확인 |

명세 집계는 **검토 7개: 직접 제공 1·미제공 4·추가 조사 2**다. 직접 제공 1개는 공고 쪽 S 값이며 거래 쪽 대응 경로가 아니다. 실거래 단위는 **검토 표본 0건, 대응 비율 미산출**이다.

### 2.2 공급면적의 법령상 구분을 확인한다

주택공급에 관한 규칙 제21조제5항은 세대별 공급면적을 주거전용면적으로 표시하게 한다. 그 외에 두 종류의 공용면적을 따로 표시할 수 있다. **주거공용면적**은 계단·복도·현관 등 지상층 공용면적이다. **그 밖의 공용면적**은 지하층·관리사무소·노인정 등이다. 제2조제5호는 주택공급면적을 바닥면적으로 정의한다.

공고문 표의 ‘공급면적’이 주거전용과 주거공용의 합인지는 각 공고 표 머리글로 확인해야 한다. 이 정의를 이번 작업에서 법령 정의로 확정하지 않았다. 대장의 ‘공용’ 행을 모두 더하면 지하주차장 같은 그 밖의 공용이 섞일 수 있다. 이것이 대장·인허가 경로의 핵심 위험이다. 기존 E-02 한 건에서는 PDF 공급면적 105.8939㎡와 API `SUPLY_AR`이 일치했다. 이 일치를 다른 공고로 일반화하지 않는다.

### 2.3 단지·권리 식별 필드를 대조한다

| 확인한 사실 | 판단에 미치는 영향 |
| --- | --- |
| 이번에 확인한 매매 명세의 출력 목록에 `sggCd`·`umdCd`·`landCd`·`bonbun`·`bubun`·도로명 코드·`aptSeq`(단지 일련번호)가 있음 | 주소 교차 확인은 기술적으로 가능. `aptSeq`와 K-apt `kaptCode`의 대응을 알려 주는 공식 설명은 두 카탈로그 모두에 없음 |

출처별 근거와 경계는 다음과 같다.

- **공공데이터포털:** 조회한 8개 카탈로그 모두 ‘이용허락범위 제한 없음’과 무료를 표시한다. 공공데이터법 제3조제4항은 다른 법률의 특별한 규정이나 제28조제1항 각 호(제공중단 사유)의 경우를 제외하고 영리적 이용도 금지·제한하지 않게 하고, 제5항은 이용자에게 타인의 권리를 침해하지 않도록 법령·이용조건의 의무를 지킬 책임을 지운다. 포털 정책은 제3자 권리가 포함된 데이터에는 권리자의 이용허락이 필요하다고 안내한다. 같은 정책은 공공누리 ‘AI유형’도 소개하지만 이번 카탈로그들은 공공누리 유형이 아닌 ‘제한 없음’을 표시한다. 따라서 LLM 입력이 이 표시에 포함되는지는 팀이 확인해야 한다. 개발계정 트래픽(10,000, 청약홈 40,000)에는 기간 단위가 적혀 있지 않다.
- **청약홈 공고 PDF:** 청약홈 API 카탈로그의 ‘이용허락범위 제한 없음’ 표기만으로는 공고 PDF의 활용 조건을 판단할 수 없다. 카탈로그는 PDF 자체의 이용 조건을 설명하지 않는다. 입주자모집공고는 사업주체가 한다(규칙 제21조제1항). 청약홈 첫 화면 하단에는 저작권·이용약관 페이지 링크가 없다. 부동산원 저작권 정책은 부동산원이 저작재산권 전부를 가진 저작물에만 적용된다. 저작권법 제7조제2호(국가·지방자치단체의 고시·공고)와 제24조의2제1항(국가·지방자치단체 저작물의 자유이용, 같은 항 각 호의 예외 있음)이 민간 사업주체의 공고문에 적용되는지는 해석이 필요하다. 근거 없이 판단하지 않는다.
- **카카오:** 서비스 약관 제11조제3항은 서비스로 얻은 데이터를 사전 승낙 없이 복사·복제·변경하거나 타인에게 제공하는 행위를 금지한다. 운영정책 제5조는 사용자 환경 개선 외의 목적으로 캐시하거나, 캐시한 뒤 최신 상태로 유지하지 않는 행위를 금지한다. 보고서에 좌표·주소를 고정해 저장하거나 다른 사용자 분석에 재사용하는 것이 이 조항과 양립하는지는 사전 승낙 필요 여부를 포함해 확인해야 한다.
- **ODsay:** 4.5.10은 사전 동의 없는 결과 데이터의 복제·저장·가공·배포·제3자 전송을 금지한다. 7.3은 결과 데이터의 권리가 회사에 있고 이용자가 사용권을 취득하지 않는다고 정한다. 회원 이용 제한 항목은 사전 동의 없이 기본 용도 외 목적(데이터 분석 등)으로 쓰는 것을 막는다. 기존 [데이터 관리](../data-handling.md)의 4.5.10 기록은 그대로 유효하다. 2026-11-09 이후 약관 변경 여부는 이전 사본이 없어 비교하지 못했다.
- **국가법령정보:** 저작권법 제7조제1호는 헌법·법률·조약·명령·조례·규칙을 보호 대상에서 제외한다. 이것은 법령 문언의 저작권 상태이며 OPEN API의 이용 조건이 아니다. API 조건 페이지는 열람에 실패했다(표 1의 22·23).
- **NAVER API HUB:** 공개 API 문서에는 호출 한도와 필드만 있다. 저장·표시·LLM 조건이 담긴 약관 원문을 공개 문서에서 찾지 못했다. 관련 가이드는 403으로 열리지 않았다.
- **LLM 공급자와 자동차 경로:** 모델 공급자의 입력 데이터 조건은 이번 범위에서 검토하지 않았다. 자동차 경로는 출처가 정해지지 않아 착수하지 않았다(D-06·D-07).

- 이 문서는 문서 열람 결과다. 실제 응답의 필드 존재, 전국 적용성, 이용 허락을 검증하지 않았다.
