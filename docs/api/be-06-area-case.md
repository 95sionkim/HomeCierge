# BE-06 구의동 주변 단지 공급면적 대응 재시도

2026-11-22(한국시간) · V1 주변 단지 검증 · M2 수작업 대조의 후속

**BE-05와 같은 광진구 963행에서 구의동 주변 거래를 새로 조사했다. 계약일에 적용되는 공급면적이 공식 자료로 입증된 주변 거래는 0행이다.** 집중 조사한 e편한세상광진그랜드파크의 유효 27행은 단지 연결까지 확인했다. 공급면적은 확인 0행·불일치 0행·보류 27행이다. 현재 수집본에서 채택한 구의동 주변 유효 거래 319행 중 공급면적을 확인한 행도 0행이다. 이 가운데 292행은 단지별 주택형 정밀 조사 전이다. 따라서 `compare_snapshot`과 건수·가격·면적 통계를 대조하는 양성 사례는 만들지 못했다. 대신 새로 연결한 27행을 실제 엔진에 넣어 보류·제외·지역 판정이 수작업과 같은지 확인했다. 아래에는 대상, 분모, 확인한 공식 경로, 누락된 근거를 기록한다.

## 1. 기준과 모집단을 BE-05와 같게 고정한다

- 대상 공고·주택형과 기간은 BE-05와 같다. 강변역 센트럴 아이파크 84C의 공급면적은 9월 재공급 공고 기준 105.8939㎡다. ±5% 범위는 양 끝을 포함한 **100.599205~111.188595㎡**다. 계약일은 `LAWD_CD=11215`, 2025-11-01~2026-10-31 양 끝 포함이다. 우선 지역은 구의동이며 이 문서에서 범위를 바꾸지 않았다. [BE-05 기준](be-05-real-case.md) · [PRD §7.2](../prd/01-product-prd.md#72-지역-검색과-비교-규칙)
- 원 프로젝트의 매매·권리 XML 24페이지를 읽기 전용으로 다시 열어 행을 셌다. 페이지별 SHA-256을 이은 묶음 해시가 BE-05 §5의 두 값과 일치했다. 따라서 BE-05와 같은 모집단이다. 신규 인증 API 호출과 키 사용은 0회다. [재검산 방법](be-05-real-case.md#5-같은-모집단을-재검산한다)
- 공급면적 후보 판정은 전용면적과 섞지 않았다. 전용면적 구간은 조사 순서를 정하는 데만 사용했다. 공급면적이 확인되지 않은 행은 범위 밖으로 분류하지 않았다. [PRD §7.2.1](../prd/01-product-prd.md#721-비교-가능성과-정상-0개를-구분한다)

## 2. 우선 후보를 고르고 단지 연결을 확인한다

**e편한세상광진그랜드파크를 1순위로 정했다.** 2021-12-30에 사용승인을 받은 단지여서 2019년 최초 공고와 준공 후 공식 자료를 함께 찾을 가능성이 가장 컸다. 또한 전용 84㎡대 주택형에 유효 거래가 20행 있다. 2018년 이전에 지어진 40개 단지의 분양 공고는 청약홈 공개 목록의 조회 범위 밖이며, 이번에는 단지별 공고를 따로 탐색하지 않았다. 예외적으로 래미안 구의 파크스위트의 서울시 장애인 특별공급 안내(2016)를 열람했으나 전용면적 값만 "공급면적" 칸에 적혀 있어 근거로 쓰지 않았다. 2019년 이후에 지어진 다른 8개 단지는 거래된 전용면적이 모두 80㎡ 미만이다. 이 8개 단지는 조사 순서를 뒤로 미뤘을 뿐 범위 밖으로 판정하지 않았다.

분모는 두 가지 의미로 나눠 읽는다. **0/27**은 집중 조사한 한 단지에서 계약일 적용 공급면적 근거를 확보한 수다. 단지 연결은 27/27행 확인했다. **0/319**는 현재 수집본에서 채택한 구의동 주변 유효 거래 중 공급면적이 확인된 수다. 이 중 292행은 정밀 조사 전이다. 따라서 0/319를 구의동 자료 전체의 성공률이나 판정 불가능률로 읽지 않는다. 이 결과는 BE-05의 자체 거래 0/4와 별개로 산출했다. K-apt와 서울시 자료는 단지 전체 합계만 제공하므로 주택형별 공급면적을 대신하지 않는다.

### 실제 비교 엔진에서 판정을 대조한다

BE-05와 같은 XML 24페이지를 메모리에서 BE-02의 `collect_pages`·`normalize_trade`로 정규화해 `compare_snapshot`에 전달했다. 입력은 다음과 같다.

- 페이지 크기는 출처별 원래 값(실거래 1,000행, 청약홈 5행)을, 시각은 수집 기록의 값을 사용했다. 청약홈 입력은 2026-11-06 브라우저 보관본의 공고·주택형 본문이다. 이 보관본에는 HTTP 상태가 기록되지 않아 정상 응답 200으로 넣었다.
- 분석 기준 면적은 9월 공고 PDF 4쪽의 84C 105.8939㎡다. PDF의 SHA-256 `97987f527a961051724f6561aca34451e3131a23ae9e11a0c65ee53ddee1d98e`가 보관 기록과 일치했다.
- 법정동은 실거래 응답의 `sggCd`·`umdCd`·`umdNm` 7개 조합으로 선언했다. 조합마다 코드와 이름은 1:1이다. 구의동 코드는 K-apt `bjdCode=1121510300`과 대조했다. 다른 6개 동은 이번에 공개 코드표와 따로 대조하지 않았다.
- 단지 연결은 대상 유효 4행과 그랜드파크 유효 27행에만 입력했다. 대상 4행은 BE-05와 같은 지번·단지명 근거를 사용했다. 그랜드파크 27행은 `aptSeq=11215-4893`, `umdCd=10300`, `jibun=680`, 도로명 광나루로를 근거로 연결했다. 두 단지 모두 `supplyAreaM2`는 넣지 않았다. 해제 행은 연결하지 않았다.

엔진은 구의동 우선 범위를 **보류(`held`)**로 판정했다. 확정 후보는 0개, 미해소 주변 거래는 319행이다. 수집 기록 24개는 완료 16·빈 응답 8로 수집은 완료(`complete`)였고, 후보 판별은 미완료(`incomplete`)였다. 거래 종류별로는 매매가 보류(미해소 319행)다. 분양권·입주권은 구의동에 대상 단지 외 권리 거래가 없어 정상 0개다. 매매 보류가 남아 광진구로 확대하지 않았다(`expansion=null`, `priority_held`). 전체 결과는 부분(`partial`)이며 순위 완료는 `false`, 표시된 비교 단지는 0개다.

수작업 판정과 엔진 결과는 위 다섯 구분의 건수가 모두 일치했다. BE-05와 비교하면 319행 중 27행의 보류 사유가 단지 식별에서 공급면적 대응으로 바뀌었다. 비교 후보·지역 판정은 같다. 공급면적이 확인된 주변 거래가 없으므로 가격·건수 통계는 산출하지 않았다.

## 6. 다음 근거 경로를 정한다

1. **그랜드파크의 2019년 최초 모집공고와 변경 공고를 공식 사본으로 확보한다.** 청약홈 공개 목록에는 없으므로 사업주체·신탁사·관리주체 보관본이나 운영기관 열람 경로가 필요하다. 대외 연락이나 새 계정이 필요하면 사용자가 결정한다.
2. **준공 후 주택형별 주거공용 포함 면적의 공식 근거를 확보한다.** 사용승인 도서·분양면적 확정 안내 등 공식 자료가 후보다. 건축물대장 전유·공용면적만으로는 주거공용을 구분할 수 없다. 새 API 승인이나 로그인 열람이 필요하면 사용자가 결정한다.
3. **두 근거를 확보하면 다음 순서로 검산한다.** 공고 주택형별 세대수×전용면적의 합을 K-apt 전용면적 합 69,744.3544㎡와 대조한다. 관리비부과면적 86,973.67㎡가 공급면적 합인지는 정의를 먼저 확인한다. 합계가 일치해도 정황 근거로만 쓴다. 이후 실거래 전용면적과 주택형 하나의 정확한 대응을 확인하고 100.599205~111.188595㎡ 판정을 한다. 확인된 행만 `compare_snapshot`에 입력해 손계산의 건수·최소·중위·최대와 대조한다.
4. 2018년 이전 건축 40개 단지는 공개 공고 경로가 없다. 건축물대장과 공식 도서의 주거공용 구분 근거가 있어야 같은 절차를 적용할 수 있다.

**이번 시도에서 확인한 범위는 구의동 주변 거래의 분모와, 공식 경로별 누락 위치까지다.** 표본 선택은 한 단지에 집중했으며, 다른 구의동 단지 292행은 공식 경로를 탐색하지 않았다. 결과를 바꾸는 근거가 확보되기 전에는 ±5% 범위·전용면적 기준·지역 범위를 조정하지 않는다.
