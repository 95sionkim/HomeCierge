# API 인계 상태

기준일은 2026-11-09다. 10서비스·14조회 실제 응답과 제한된 연결 시험을 확보했고 [PRD 초안 v0.1](../prd/01-product-prd.md)을 작성했다. 서비스 출시·전체 지역 보장·공급면적 최종 비교가 완료된 상태는 아니다.

| 확보한 결과를 확인한다 | 개발 시 적용할 한계를 확인한다 |
| --- | --- |
| 청약홈 4조회, 실거래 매매/권리, K-apt 목록/기본, 건축물대장, 카카오, 법령 목록/본문, ODsay, 뉴스 | 10서비스·14조회는 제한된 실응답 확인. 전 지역·유형·계정 운영 한도는 미검증 |
| 광진구 12계약월 매매 956행·해제 45행, 별도 권리 7행·해제 1행 | 매칭 전 매매 유효 911행. 사용일 기준 최근 1년과 날짜 경계가 다름 |
| 과거 전용면적 ±1㎡·5km 후보 75개 중 33개 연결·42개 보류 | 현행 동→구 정책과 공급면적 기반 최종 선정 검증이 아님 |
| 공식 PDF 1건 12쪽·46항목 검수, 72개 검사 | 다른 회차 병합 거부 확인. 전체 공고 자동 추출·개인 자격 판정은 미검증 |
| 법령·교통·뉴스 검사 80개 통과 | 실제 출퇴근·뉴스 사실성·지역 적합성·개인 법령 적용은 미검증 |

현재 확정 규칙은 같은 법정동 우선, 정상 0개이면 같은 구 확대, 최대 5단지, 최근 1년 및 사용자 기간, 공급면적 비교다. 미확인 후보나 실패가 있으면 정상 0개를 확정하지 않는다. 자세한 상태 표는 PRD §6을 따른다.

미정 결정은 D-01 면적, D-02 지역·기간, D-03 선정·가격·통계, D-04 초기 흐름, D-05 사용자·성과, D-06 대화·기술, D-07 운영이다. API 발급이 완료됐다는 이유로 보조 기능의 MVP 포함 여부나 모델·스택을 확정하지 않는다.

OpenAI는 원 프로젝트의 설정 존재만 확인했다. 인증·모델 호출·품질·비용은 검증하지 않았다. 실제 인증값은 GitHub에 포함하지 않는다.

검증 수치의 상세는 [통합 보고서](validation-20261109.md), 재현 범위는 [API 안내](README.md), 다음 작업은 [개발 시작 안내](../development.md)를 확인한다.
