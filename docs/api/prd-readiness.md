# API 인계 상태

데이터 검증 기준일은 2026-11-09다. 10서비스·14조회 실제 응답과 제한된 연결 시험을 확보했다. [PRD v1.0](../prd/01-product-prd.md)은 2026-11-10의 사용자 결정 36개를 반영한 요구 기준본이며, 요구 변경이 과거 검증 범위를 넓히지는 않는다. 서비스 출시·전체 지역 보장·공급면적 최종 비교가 완료된 상태는 아니다.

| 확보한 결과를 확인한다 | 개발 시 적용할 한계를 확인한다 |
| --- | --- |
| 청약홈 4조회, 실거래 매매/권리, K-apt 목록/기본, 건축물대장, 카카오, 법령 목록/본문, ODsay, 뉴스 | 10서비스·14조회는 제한된 실응답 확인. 전 지역·유형·계정 운영 한도는 미검증 |
| 광진구 12계약월 매매 956행·해제 45행, 별도 권리 7행·해제 1행 | 매칭 전 매매 유효 911행. 사용일 기준 최근 1년과 날짜 경계가 다름 |
| 과거 전용면적 ±1㎡·5km 후보 75개 중 33개 연결·42개 보류 | 현행 동→구 정책과 공급면적 기반 최종 선정 검증이 아님 |
| 공식 PDF 1건 12쪽·46항목 검수, 72개 검사 | 다른 회차 병합 거부 확인. 전체 공고 자동 추출·개인 자격 판정은 미검증 |
| 법령·교통·뉴스 검사 80개 통과 | 실제 출퇴근·뉴스 사실성·지역 적합성·개인 법령 적용은 미검증 |

현재 비교는 모든 거래 종류에 같은 동·읍·면을 공통 적용하고 전체 정상 0개일 때만 같은 구 또는 구 없는 시·군으로 확대한다. 전체 고유 주변 최대 5개, 공급면적 ±5% 안의 면적 차이·직선거리순, 현재 범위 안의 직접 교체, 자체 거래 별도 참고를 적용한다. 기간은 당월 포함 조회일까지 최근 1년 또는 사용자 설정 범위이며 신고 지연·정정 가능성을 표시한다. 결론을 바꿀 미확인이나 실패가 있으면 정상 0개를 확정하지 않는다. 자세한 절차는 PRD §6을 따른다.

단지별로 선택 주택형과 가장 가까운 공급면적으로 순위를 정하고 그 면적의 거래만 종류별 통계에 사용한다. 유효 거래 1건 이상이면 비교에 포함하며 1~2건은 적은 표본임을 표시한다. 다른 면적의 더 많은 거래를 합쳐 표본을 늘리거나 적은 건수를 동의 정상 0개로 바꾸지 않는다.

공고 탐색은 시·군·구 복수 선택·예산 필수, 공급면적 최소~최대(㎡·평)와 입주 시작월~종료월 선택을 적용한다. 입주는 공식 예정 기간과 겹침으로 판단한다. 아파트 신규분양·무순위·잔여세대·재공급을 지원하며 접수 중 마감일순→예정 시작일순이 기본이고 종료는 사용자 선택 시 포함한다. 충족 목록과 확인 필요 목록을 기본 분리 제공한다. 이 범위 확정은 유형별 필드·서식·접수 상태의 검증 완료를 뜻하지 않는다.

다른 탐색 조건을 충족하면서 분양가+필수 옵션이 예산 이내인 주택형·호실이 하나라도 확인되면 공고를 포함하고 해당 항목을 표시한다. 초기 분석은 한 번에 한 공고·한 주택형이며 여러 공고의 나란히 비교는 후속이다. 공식 PDF는 자동 확보 후 실패 시 업로드로 보완하고, 원문 대조·일관성 자동 점검을 통과한 값을 사용한다. 해당 자동화는 제품 요구로 채택했으며 위의 단일 PDF 검수 결과가 구현·검증을 대신하지 않는다.

기초 자금표·법령 근거 탐색·출퇴근 경로 조회는 초기 범위에 모두 포함했다. 자금표는 현재 보유 자금과 날짜별 추가 자금을 확정·예상으로 구분한다. 상세 자금은 분석별로 저장하고 탐색 조건·목적지는 확인 후 공유 프로필에 저장한다. 우선 설계 대상은 청약 경험이 적은 실거주 목적의 첫 집 마련자다. 법령 적용·실제 경로·자금 대조의 구현 검증과 사용자 가치 검증은 별도다.

첫 사용부터 로그인 후 탐색·분석하며 계정 저장과 기기 간 복원을 지원할 예정이다. 출퇴근은 대중교통·연결 도보와 자동차 경로를 모두 초기 지원 범위로 정했다. 기존 `searchPubTransPathT` 시험과 자동차 경로는 구분하며 자동차 데이터 소스·실응답·연동·운영 조건은 새로 검증해야 한다.

남은 결정은 D-01 면적, D-02 지역·기간, D-03 선정·가격·통계, D-04 상세 흐름, D-05 사용자 가치·성과, D-06 대화·기술, D-07 운영이다. 보조 기능의 초기 포함은 기능별 운영 조건이나 모델·스택까지 확정한 것을 뜻하지 않는다.

OpenAI는 원 프로젝트의 설정 존재만 확인했다. 인증·모델 호출·품질·비용은 검증하지 않았다. 실제 인증값은 GitHub에 포함하지 않는다.
