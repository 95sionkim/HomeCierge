외부 API는 필요한 계기에 조회합니다

현재 저장소의 조회 설정을 서비스 단계에 연결한 제안입니다. Supabase 인증·DB·파일 접근은 아래 외부 데이터 조회와 별개입니다.

출처를 구분한다시점을 정한다조회 계기를 정한다사용할 값·주의점을 확인한다
PDF 확보는 별도 문서 경로입니다. 공고 링크의 공식 상세 페이지에서 첨부를 확보합니다. 자금표·예산 판정·직선거리·가격 통계는 자체 계산이며 은행·대출 심사 API를 전제하지 않습니다.

다시 열기 · 다시 계산하기 · 다시 수집하기

자료를 재사용하려면 출처 허용 범위·수집 완전성·버전·정해질 최신성 기준을 모두 확인해야 합니다.

저장 보고서는 고정합니다. 새 프로필·새 거래·추가 보조 정보는 이전 보고서를 덮어쓰지 않습니다. 새 분석이나 갱신 결과를 별도 버전으로 남깁니다.
확정 요구와 설계 제안을 구분합니다. 첫 로그인·공급면적 비교·정상 0개 시 확대·계정 저장은 PRD 요구입니다. 사전 수집·보완 조회·병행 시점은 제안이며, 실제 탐색·분석·PDF·보조 기능은 개발 대상입니다.
