# 대화형 UI와 GitHub PRD 대조 결과

> 이전 10단계 시안의 검토 기록입니다. 최신 21개 화면과 구현·검증 범위는 [캐릭터 기반 UX 문서](conversation-mascot-ux.md)를 확인하세요.

## 결론

대화형 시안은 **PRD의 일부 핵심 규칙을 참고한 레이아웃·인터랙션 제안**이다. 현재 PRD의 초기 필수 기능 전체를 반영한 화면 명세나 서비스 구현으로 볼 수 없다. R-01~R-18을 대조한 결과 **13개 부분 반영, 5개 핵심 화면 미포함**이다. 이는 화면 표현의 분류이며 제품 테스트 통과율이 아니다. A-01~A-59를 실행한 것으로 해석하지 않는다.

대화가 중심이고 후보·상세 결과가 옆에 놓이는 배치는 PRD §5·§7.4 P-01·§9의 허용된 설계 제안과 맞는다. 세 칸 레이아웃·패널 너비·화면 10단계는 PRD의 확정 요구가 아니라 이번 디자인 선택이다.

## 이번에 바로잡은 표현·동작

1. **탐색 지역과 비교 지역을 분리**했다. 공고 탐색 예시는 ‘합성구’, 선택 공고의 비교 소재지는 ‘합성구 가람동’으로 표시한다. 이전 동 단위 탐색 표기는 R-15/§5.1에 맞지 않았다. 복수 선택과 검증된 지역 코드는 여전히 보완해야 한다.
2. **필수 조건 없는 임의 진행을 막는 예시**를 추가했다. 첫 자유 입력에서 지역·예산을 찾지 못하면 ‘입력 필요’와 필수 조건 편집을 보여주고 후보 열기 버튼을 비활성화한다. 단순 형식 추출은 자연어 이해나 지역 식별 검증의 대체가 아니다. 상단 단계 선택과 추천 질문은 명시적인 고정 예시 시연이다.
3. **사용자 입력과 고정 후보를 구분**했다. 임의 입력에도 합성구·8억 원이 입력된 것처럼 표시하던 동작을 수정했고, 후보는 실제 조건으로 검색·계산한 결과가 아님을 명시한다. 자연어 의도 분류와 실제 검색은 미연결이다.
4. **선택 전에 선택 공고가 나타나던 표현을 수정**했다. 후보 단계의 오른쪽 패널은 공고 선택을 요청하며, 주택형 선택 메시지 이전에는 입력창에 선택 공고 태그를 고정하지 않는다. 완전한 주택형 선택 화면은 아직 필요하다.
5. **비교 기간을 기본값으로 오해하지 않게 표시**했다. 기존 합성 통계는 2026.10.10–10.31의 짧은 기간에 대한 값이므로 ‘사용자 지정 기간의 합성 예시’로 명시했다. PRD 기본은 2026.11.10 기준 2025.11.11–2026.11.10이며 당월을 포함한다. 과거 예시 값을 최근 1년 통계로 바꾸어 주장하지 않았다.
6. **PDF 자동 확보가 우선임을 안내**했다. 업로드는 자동 확보 실패 후의 보완 경로이며, 이 시안에서 파일 선택만으로 확보·검증이 완료되는 것은 아니다.

수정한 항목도 화면 시안의 일부 동작일 뿐 R-01·R-06·R-15 전체의 수락 판정을 통과한 것이 아니다.

## 뉴스와 보고서의 문서 간 미해결 항목

PRD R-10·R-11은 뉴스 제공과 보고서 정리를 초기 범위로 둔다. 반면 같은 저장소의 [뉴스 출처 이용 검토](api/be-10-news-sources.md)는 검색결과의 LLM 입력·장기 보고서 저장·PDF 재사용에 별도 권한을 요구한다. 기사 내용을 보고서에 저장하지 않는다는 문구 자체를 오류로 보지는 않는다. 그러나 그 문구만으로 뉴스 기능을 빼도 되는 것은 아니다.

화면에는 독립적인 뉴스 조회 영역을 추가해야 한다. 보고서에서는 검색 조건·조회 시점·출처·재조회 경로와 누락 이유를 어떻게 보존할지 **D-07의 이용 범위와 R-11을 함께 해결**해야 한다. 본 검토에서 새 이용 허가를 얻거나 권한을 확정하지 않았다.

## 다음 디자인 보완 순서

1. 인증 시작·만료, 필수 시·군·구 복수 선택·예산, 선택 면적·입주 범위, 후보 상태·정렬과 확인 필요 분리.
2. 공고 회차·PDF 확보/충돌·가격/면적 점검, 명시적인 주택형·호실 선택.
3. 정상 0개/미확인/실패별 지역 판단, 종류별 통계·선정 순서·자체 거래·후보 교체와 비교 조건 승인.
4. 날짜별 자금 편집, 법령 근거, 수단별 출퇴근, 독립 뉴스 결과.
5. 프로필 취소·버전 충돌, 보고서 저장·다시 열기·PDF, 개별/계정 삭제.

이 기능들은 대화 중심 구조를 유지하며 선택 카드·승인 카드·오른쪽 자료 패널 안에 배치할 수 있다. 대화 UI를 채택했다는 이유로 필수 입력·선택·승인·출처·실패 상태를 숨기거나 생략하면 안 된다.

## 검증 범위

브라우저에서 필수 조건 누락·지역/예산 입력 확인·후보 단계 선택 전 패널·기간 문구·프로필 승인 전후 분리 및 모바일 폭을 점검한다. 기존 시안은 AI나 제품 API에 연결되어 있지 않다. 외부 API·DB·인증·A-01~A-59의 종단 검수는 이번 디자인 대조 검토에 포함하지 않는다.
