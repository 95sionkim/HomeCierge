# 캐릭터 컬러 기반 대화형 UX 시안

2026-11-24 · `backup/backend-foundation-20261123`의 PRD v1.2 기준. 사용자가 제공한 2026-11-13 Understand–Find–Verify–Explain–Alert 기능설계 구성도를 화면 순서에 반영했다. 구성도는 PRD v1.1을 인용하므로 자금표 등 세부 규칙은 최신 v1.2를 우선한다.

## 결과와 범위

`public/conversation.html`에 21개 화면을 구성했다. `/conversation.html?view=flow`는 단계별 목차다. 캐릭터·폰트를 포함한 단일 HTML과 PNG 캡처는 별도 전달 패키지로 제공한다. 이 파일은 대화형 디자인 프로토타입이며 실제 Supabase 인증·AI·외부 API·계정 저장을 새로 연결한 제품 화면이 아니다. 기존 연결 기능은 `public/index.html`과 그 모듈에 그대로 남아 있다. 이번 변경은 기존 API 계약·계산 로직·인증·DB를 수정하지 않는다.

앞선 [PRD 대조](conversation-prd-review.md)는 이전 시안에 대한 기록으로 보존한다. 이번 보완으로 누락된 기능의 화면 진입점과 상태를 추가했지만 R-01~R-18 또는 A-01~A-59 전체를 구현·통과한 것으로 바꾸지 않는다.

## 정보 위계와 흐름

- 상단에는 현재 작업과 단계, 본문에는 사용자 요청·홈시어지 설명·핵심 선택/결과·다음 행동을 놓는다. 이전 단계는 접어서 읽는 부담을 줄인다.
- 공고 목록은 충족·확인 필요를 분리하고, 같은 공고의 미확인 호실은 그 공고 안에 표시한다.
- 실거래 화면에서는 선택 공고와 핵심 비교를 먼저 보여주고 상세 비교 조건은 펼쳐 본다. 우측 요약에는 현재 조건·선택 주택형·출처·연결 기능을 둔다.
- 화면별 주요 행동은 다음 한 단계로 이어진다. 자금·법령·뉴스·경로는 독립적으로 열 수 있어 한 자료의 오류가 전체 검토를 막지 않는다.
- 760px 이하에서는 내비게이션을 메뉴로, 자료 요약을 열고 닫는 패널로 전환한다. 표는 표 내부에서 가로 스크롤한다.

## 동작하는 시연과 한계

- 4개 합성 공고의 같은 주택형·호실에 예산·공급면적 범위·입주 기간 겹침을 적용한다. 예산과 같은 금액도 포함하고 필수 옵션 미확인은 보류한다. 표시용 반올림 전 공급면적으로 판정한다. 지역 선택은 두 개의 명시된 시·군·구 예시만 지원한다.
- 문서 확보 성공/실패/회차 충돌을 전환할 수 있다. 업로드는 파일 선택만 표시하며 판독·전송·공식성 검증을 하지 않는다.
- 통계·거리·단지 특성·접수 상태·공고일·페이지는 합성이다. 기본 비교 기간은 고정 시안 기준 2026-11-24까지 최근 1년(2025-11-25 시작, 당월 포함)이다. 실제 서비스에서는 실행 기준일에 맞춰야 한다.
- 비교 조건은 변경 전후를 확인하고 적용한다. 새 범위의 수집·선정을 검증하지 않았으므로 기존 통계를 새 조건의 결과로 재표시하지 않고 보류한다. 단지 교체는 승인 구조만 있으며 실제 통계를 교체하지 않는다.
- 자금표는 특정 호실의 합성 계약금 일정 한 건으로 시연한다. 날짜별 여러 입금·여러 납부회차의 전체 누적 계산기는 아니다. 미확인 중도금·잔금은 보류한다. 보유 자금·예산 상한을 섞지 않고 새 대화에 상세 자금을 자동 복사하지 않는다.
- 법령 판본·개인 자격은 미확인으로 표시한다. 원문 링크는 법령 조회 입구이며 특정 공고일 시행 판본으로 검증한 링크가 아니다.
- 경로는 수단별 실패/미제공과 합성 예시를 보여준다. 뉴스는 실제 기사를 만들지 않고 필드 배치를 보여주며 화면 이탈 시 비운다. 기사 발췌·본문의 보관/PDF 재사용 권한은 확정하지 않는다.
- 보고서는 이 탭 메모리에 같은 조건·금액·가정·부족액을 고정해 다시 연다. 이후 조건·프로필 변경으로 덮지 않는다. 인쇄는 동일 DOM을 사용한다. 서버 저장·계정 격리·기기 간 복원·실제 삭제 완료 검증은 별도 연결 과제다.
- 자유 입력은 키워드로 화면을 연결하고 일부 예산·지역을 변경안으로 보여주는 시연이다. AI 이해·추출·Agent 실행이 아니다.

## 확인한 범위

1440×1000, 390×844에서 21개 화면의 가로 넘침·이미지 로딩·런타임 오류를 점검했다. 로그인 안내, 지역 필수, 예산 동일 경계, 같은 공고 중복 집계 방지, 옵션 미확인/PDF 회차 충돌, 당일 입금 전후 및 납부 후 유입 제외, 공유 프로필 취소/승인, 저장 요약 유지, 비교 조건 승인·새 조건 통계 보류, 경로 부분 실패, 뉴스 이탈 제거, 비활성 알림, 모션 감소를 브라우저에서 확인했다. 기존 기능 브라우저 회귀 14개·빌드·저장소 검사도 통과했다. 실제 API·Auth·A-01~A-59 전체 검수로 해석하지 않는다.

추가 기본 검사: Python 404건 중 403건 통과, `test_funding_capture.FundingCaptureTests.test_live_save_reads_real_synthetic_pdf_once_and_retries_same_atomic_payload` 1건이 `JSONDecodeError`로 실패했다. 변경 전 HEAD를 임시 디렉터리에 내보내 같은 자금 워커 검사 5건을 실행해도 동일한 1건 오류가 재현됐다. 이번 시안에서 자금 워커 코드를 변경하지 않았으며, 이 기존 오류의 수정은 이번 디자인 작업에 포함하지 않았다.
