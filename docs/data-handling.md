# 데이터와 인증정보 관리

이 저장소는 공개 개발 자료다. 제품 요구, 직접 작성한 검증 코드, 필드 대응, 검증 수치, 합성 자료를 공유한다. 비공개 원자료와 공개 테스트를 구분한다.

| 자료를 구분한다 | 저장소에서 처리한다 |
| --- | --- |
| API 키·비밀번호·OTP·개인 계정 운영 기록 | 포함하지 않는다. `.secrets/` 또는 서버 실행 환경에서 관리 |
| 실제 API 응답·교통 경로·뉴스 발췌/본문 | 포함하지 않는다. 확보와 재배포 허용은 별도 |
| 공고 PDF·HWP 가이드·원문 추출물 | 전체 파일을 포함하지 않는다. 공식 출처 링크·검증 요약만 제공 |
| 과거 검증 수치·보고서 해시 | `docs/api/evidence-index.json`에 공개. 원문 미포함을 명시 |
| 테스트 자료 | 합성임을 표시. 실제 사용자 조건·위치·재무정보를 사용하지 않음 |

ODsay 이용약관 4.5.10에는 사전 동의 없는 결과 데이터의 복제·저장·가공·배포·전송 제한이 있다. 운영 캐시·장기 보관·모델 입력·공유 허용 범위는 D-07에서 확인한다. 키를 등록했다는 사실만으로 결과 재사용 허용을 가정하지 않는다. [ODsay 정책 및 약관](https://lab.odsay.com/doc/totalPolicy), 확인 2026-11-09.

NAVER 뉴스의 원문·발췌·LLM 입력·보관 허용 범위와 계정별 과금·한도도 미확인 항목이다. 공공 API와 공고 PDF 역시 자료별 출처·표시·재사용 조건을 확인한 뒤 실제 데이터를 공유한다. 현재 저장소는 실제 데이터의 재배포 허가를 선언하지 않는다.

기존 진단 스크립트는 실행하면 `api-evidence/`에 응답을 저장한다. ODsay·뉴스처럼 보관 조건이 미확인인 서비스는 조건 확인 전 저장 스크립트를 실행하지 않는다. 기본 테스트와 CI는 인증값·네트워크·실응답 저장을 사용하지 않는다.

`.gitignore`는 추적하지 않는 파일을 제외하는 장치다. 이미 추적된 비밀정보를 제거하거나 과거 이력을 정리해 주지는 않는다. 게시 전에는 실제 커밋 대상과 문서·샘플을 확인한다. 공개 테스트의 문자열 제거 검사는 모든 형태의 비밀정보 탐지를 보장하지 않는다.

새 체크아웃에 키가 필요하면 [API 설정](api/README.md)을 따른다. 키를 채팅·PR·이슈·스크린샷에 복사하지 않는다. 오픈소스 라이선스 부여와 제3자 라이브러리의 배포 조건은 아직 별도 결정이므로 이 저장소에 임의의 라이선스를 추가하지 않았다.
