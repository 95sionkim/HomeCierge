# Aurora · AI 청약 탐색 시안

2026-11-24. 기존 Periwinkle 시안과 비교할 수 있는 그라데이션 버전이다. 사용자의 요청에 따라 LLM 기반의 대화형 청약 탐색이라는 성격을 첫 화면에서 더 드러낸다. [원래 시안](../public/conversation.html)과 [새 시안](../public/conversation-aurora.html)은 동일한 상태·합성 자료·PRD 흐름을 사용한다.

## 표현과 위계

- 캐릭터 뒤에 블루·라벤더·옅은 핑크의 오로라 배경과 타원 궤도를 배치한다. 공고·가격·자금이 대화 속에서 연결되는 모습을 표현한다.
- 제목 두 번째 줄과 대화 입력창 테두리, 주요 행동에 그라데이션을 적용한다. 입력창을 시작 화면 중앙으로 올리고 예시 질문 세 개를 바로 아래에 놓는다.
- “AI와 함께 찾는 나의 첫 집”, “질문을 조건으로 → 조건에 맞는 공고로 → 근거 있는 검토로”로 서비스 성격과 흐름을 설명한다.
- 조건 확인·공고 탐색·가격 검증·자금·근거·보고서에는 현재 단계의 작업을 설명하는 짧은 라벨을 둔다. 검색 대기에는 돋보기 캐릭터와 은은한 빛을 적용한다.
- 금액·면적·실패/보류 상태·출처·보고서 본문은 읽을 수 있는 단색을 사용한다. 그라데이션으로 수익·자격·판정을 보증하는 인상을 주지 않는다.
- 작은 화면에서는 같은 순서로 세로 배치하고 배경·캐릭터 모션은 시스템의 모션 감소 설정을 따른다.

## 기능 경계

예시 질문은 입력창에 질문을 채우며 자동 실행하지 않는다. 전송 후 탐색·검토는 로그인 안내를 거친다. 화면 안의 AI 표현은 서비스 디자인 제안이며 실제 LLM 호출을 추가한 것이 아니다. 하단에 합성 화면 시안과 실제 조회·AI 응답이 아님을 표시한다.

[PRD 연결과 UX 문서](conversation-mascot-ux.md)의 범위를 유지한다. 비교 규칙·예산·자금 계산·프로필 승인·정상 0건/미확인/오류 구분을 변경하지 않는다. Alert는 확장 제안으로 남긴다.

## 파일과 생성

- 페이지: [conversation-aurora.html](../public/conversation-aurora.html)
- 그라데이션 스타일: [conversation-aurora.css](../public/app/conversation-aurora.css)
- 공통 화면 동작: [conversation.js](../public/app/conversation.js). `data-design="aurora"`가 있을 때만 새 시작 화면을 표시한다.
- 다운로드용 단독 파일: [homecierge-aurora.html](../design/homecierge-aurora.html)

```sh
node scripts/export_conversation_design.mjs --aurora
```

기존 버전은 인자 없이 생성한다. 두 파일은 각각 폰트·캐릭터·스타일·동작 코드를 포함한다. 실제 API·인증·서버 저장을 실행하지 않는다.

## v1.0 캐릭터 보완

7개 포즈의 눈을 크게 조정하고 완료 포즈의 감은 눈 곡선을 두껍게 다듬었다. 대화 아바타는 36px로 늘렸다. 36/43/60/128px 표시 크기와 실제 홈·모바일 화면에서 확인했고, 투명 배경의 정사각 PNG 7종을 유지한다.

검증: 데스크톱·모바일의 21개 화면, 필수 조건·승인·가격 보류·당일 입금 전후·프로필·보고서 보존·경로 부분 실패·뉴스 이탈·확장 알림 비활성의 합성 브라우저 검사를 통과했다. 단독 HTML의 예시 질문·로그인 안내·조건 승인·원래 버전 유지·모션 감소도 확인했다. 실제 LLM/API 통합·제품 수락 완료와는 구분한다.
