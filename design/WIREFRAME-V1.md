# 홈시어지 와이어프레임 v1.0

2026-11-24 · 사용자가 Aurora 그라데이션 시안을 첫 와이어프레임 기준으로 선택했다.

기준 화면은 [Aurora HTML](homecierge-aurora.html)이며 디자인 설명은 [Aurora 설계 문서](../docs/conversation-aurora-design.md), 화면과 기능의 연결은 [PRD·UX 문서](../docs/conversation-mascot-ux.md)를 따른다.

[큰 눈 캐릭터·실제 표시 크기 미리보기](mascot-states-v1.png)

## v1.0 기준

- 블루·라벤더 그라데이션과 말랑한 집 캐릭터를 사용한다. 작은 아바타에서도 읽히도록 눈을 크게 다듬는 보완을 v1.0에 포함한다.
- 홈은 AI 청약 탐색 안내 → 대화 입력 → 예시 질문 → 단계 흐름 순서로 배치한다.
- 초기 기능은 Understand → Find → Verify → Explain으로 연결한다. Alert는 비활성 확장 와이어프레임이다.
- 21개 화면에서 한 공고·한 주택형, 확인된 가격·면적·원문 근거, 분석별 자금, 프로필 승인 흐름을 유지한다.
- 정상 0건·미확인·조회 실패를 구분한다. 그라데이션과 캐릭터는 상태·수치·다음 행동의 가독성을 보조한다.
- 데스크톱과 모바일을 지원하고 모션 감소 설정을 따른다.

이 버전은 **합성 자료로 동작하는 디자인 와이어프레임**이다. 사용자의 디자인 선택은 실제 LLM·공공 API·인증·계정 저장·알림 구현 또는 PRD 전체 수락 완료를 의미하지 않는다.

이후 화면·동선·컴포넌트 개선은 v1.0을 기준으로 변경 내용을 구분해 관리한다. 직전 Periwinkle 버전은 비교용으로 남긴다.
